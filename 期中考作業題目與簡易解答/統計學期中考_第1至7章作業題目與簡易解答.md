### 【第 2 章 習題 1】圓形圖之相對頻率與角度轉換

**題目內容：**

> 圓形圖顯示可樂的相對市占率。百事可樂的區塊部分有 90 度角，市占率為何？

**核心觀念與公式：**
```text
圓形圖（Pie Chart）是將一個圓劃分成若干扇形區塊，每個扇形區塊的圓心角度與該類別的相對次數（百分比）成正比。全圓總角度恆為 360 度（360°），因此相對頻率或市占率計算公式為：
市占率 = (該類別扇形角度 / 360°) × 100%
```

**簡易解答：**

百事可樂的市占率為 25%（即全市場的四分之一）。

### 【第 2 章 習題 9】次數分配之組數決定（2^k 法則）與組距計算

**題目內容：**

> 一份含有 230 筆觀測值，數值介於 $235 至 $567 之間的資料，你認為組距應設定為多少？

**核心觀念與公式：**
```text
建立連續型數值次數分配時，基本步驟包含：
1. 決定組數 k：採用「2 的 k 次方法則」（2^k Rule），尋找滿足 2^k ≥ n 的最小正整數 k，其中 n 為資料總筆數。
2. 計算組距 i：組距公式為 i ≥ (最高值 H - 最低值 L) / k。
3. 實務取整原則：實務上通常將計算所得的組距向上取整為便於讀者理解之倍數（如 5, 10, 50 等）。
```

**簡易解答：**

由 2^7 = 128 < 230 < 256 = 2^8，建議分成 8 組；理論組距 i ≥ ($567 - $235) / 8 = 41.5，實務上組距建議使用 45 或 50。

### 【第 2 章 習題 23】質變數與量變數之比較與測量尺度歸納

**題目內容：**

> 說明質變數與量變數的相似與相異處。請論及：
> a. 每種變數分別需要何種測量尺度？
> b. 兩種變數是否皆能用於描述母體與樣本？

**題目資料表：**

| 比較維度 | 質變數 (Qualitative Variable) | 量變數 (Quantitative Variable) |
| :---: | :--- | :--- |
| 本質定義 | 以文字、類別或屬性呈現特徵，非直接數值 | 以數字量化呈現，代表計數或度量 |
| 測量尺度 | 名目尺度 (Nominal)、順序尺度 (Ordinal) | 區間尺度 (Interval)、比例尺度 (Ratio) |
| 細部分類 | 二分變數、多類別名目、具順序等級變數 | 離散型變數 (Discrete)、連續型變數 (Continuous) |


**簡易解答：**

a. 質變數使用名目或順序尺度；量變數分為離散與連續型，使用區間或比例尺度；b. 兩種變數皆可同時用於描述母體或樣本。

### 【第 2 章 習題 27】次數分配分組組數之判定（2^k 法則）

**題目內容：**

> 一份含有 83 筆觀測值的資料，若要將此資料整理成次數分配時，你認為應分成幾組？

**核心觀念與公式：**
```text
根據「2 的 k 次方法則」（2^k Rule），分組組數 k 必須滿足：
2^k ≥ n
其中 n 為資料筆數。選取滿足該不等式的最小整數 k。
```

**簡易解答：**

因 2^6 = 64 < 83 且 2^7 = 128 > 83，建議分成 7 組。

b. P(x > 120) = e^(-120/60) = e^-2 ≈ 0.1353 (13.53%)。
c. P(45 < x < 75) = e^(-45/60) - e^(-75/60) = e^-0.75 - e^-1.25 ≈ 0.4724 - 0.2865 = 0.1859 (18.59%)。
d. 中位數：1 - e^(-x/60) = 0.50 => x = -60 × ln(0.50) ≈ 41.59 秒。

### 【第 7 章 習題 57【指數分配，課本已劃叉不考】】電腦開機時間（指數分配參考題）

**題目內容：**

> 【注意：本題為指數分配，課本原稿上已明確劃叉 (X) 標記不考，此處解答僅供學習參考】
> Eric Mouser 的電腦開機時間依循平均值為 27 秒的指數分配。他開機要花以下時間的機率是多少？
> a. 不超過 15 秒。
> b. 超過 60 秒。
> c. 介於 30 秒與 45 秒之間。
> d. 只有 10% 的開機在多少時間以內？

**核心觀念與公式：**
```text
指數分配 Exp(λ = 1/27)：累積機率 P(X < x) = 1 - e^(-x / 27)。
```

**簡易解答：**

a. P(x ≤ 15) = 1 - e^(-15/27) ≈ 1 - 0.5738 = 0.4262 (42.62%)。
b. P(x > 60) = e^(-60/27) = e^-2.222 ≈ 0.1084 (10.84%)。
c. P(30 < x < 45) = e^(-30/27) - e^(-45/27) = e^-1.111 - e^-1.667 ≈ 0.3292 - 0.1889 = 0.1403 (14.03%)。
d. 1 - e^(-x/27) = 0.10 => e^(-x/27) = 0.90 => x = -27 × ln(0.90) ≈ 2.84 秒。
